# Visual Crossing Weather

- **Coverage:** Global.
- **Use it for:** Daily and hourly weather in one response, with forecasts through 15 days. It also exposes air-quality elements and map/radar-related products.
- **Pricing:** Documentation describes no-key, commercial fair-use access. For predictable production allowance, use a registered account and review consumption pricing.

## APIs

- [Timeline Weather API](https://www.visualcrossing.com/resources/documentation/weather-api/timeline-weather-api/) — `GET https://weather.visualcrossing.com/VisualCrossingWebServices/rest/services/timeline/{location}`; request `include=days,hours`.
- [Air-quality elements](https://www.visualcrossing.com/resources/documentation/weather-api/air-quality-elements-in-the-weather-api/)
- [Weather Maps API](https://www.visualcrossing.com/resources/documentation/weather-api/weather-maps-api/)
- [Pricing](https://www.visualcrossing.com/weather-data-pricing/)
