# OpenWeather

- **Coverage:** Global, with multiple separately packaged forecast, air-pollution, and map products.
- **Use it for:** Weather APIs and map layers from one vendor.
- **Pricing:** Its API catalog promotes free self-service plans, but forecast length and granularity are product/plan specific. The catalog says 4-day hourly forecast and Air Pollution API are included in the free offering. Confirm the current entitlement in the [price page](https://openweathermap.org/price) before committing.

## APIs

- [API catalog](https://openweathermap.org/api)
- [One Call API 3.0](https://openweathermap.org/api/one-call-3) — current, minutely, hourly, daily, alerts; subscription/product terms apply.
- [5 day / 3 hour forecast](https://openweathermap.org/forecast5)
- [Air Pollution API](https://openweathermap.org/api/air-pollution) — AQI and pollutant components.
- [Weather maps](https://openweathermap.org/api/weathermaps)
- [Pricing](https://openweathermap.org/price)

## Gaps

No first-party pollen API in the reviewed catalog. Product names and free allowances have changed historically, so validate with a real account and a usage projection.
