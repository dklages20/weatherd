# Google Maps Platform: Air Quality and Pollen

- **Coverage:** Air Quality and Pollen APIs have documented country-specific coverage; pollen covers 65+ countries at 1 km resolution.
- **Use it as:** An air-quality and pollen add-on. Pollen supports daily forecasts up to five days (which can vary by location and species), health recommendations, plant details, and heatmap tiles.
- **Pricing:** Pay-as-you-go billing. A Google Cloud project, enabled billing, and credentials are required. Check current SKUs and monthly credits before implementation.

## APIs

- [Air Quality API overview](https://developers.google.com/maps/documentation/air-quality)
- [Air Quality current conditions](https://developers.google.com/maps/documentation/air-quality/current-conditions)
- [Air Quality forecast](https://developers.google.com/maps/documentation/air-quality/forecast)
- [Pollen API overview](https://developers.google.com/maps/documentation/pollen/overview)
- [Pollen forecast](https://developers.google.com/maps/documentation/pollen/forecast)
- [Pollen coverage](https://developers.google.com/maps/documentation/pollen/coverage)
- [Pollen billing](https://developers.google.com/maps/documentation/pollen/usage-and-billing)

## Gaps

Neither API supplies hourly/daily weather forecasts. Pair with a weather provider. Pollen is not a ten-day product.
