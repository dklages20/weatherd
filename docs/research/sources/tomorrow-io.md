# Tomorrow.io

- **Coverage:** Global commercial weather platform.
- **Use it for:** Current, hourly, daily, and plan-dependent minutely forecasts from one API. Documentation states 120 hourly hours and five daily days, so it cannot power a native 10-day view.
- **Pricing:** Free plan exists, with plan/rate-limit restrictions. Air-quality data is a commercial-plan feature; confirm sales plan and coverage.

## APIs

- [Weather Forecast API](https://docs.tomorrow.io/reference/weather-forecast) — `GET https://api.tomorrow.io/v4/weather/forecast`; request `timesteps=1h,1d`.
- [Weather API documentation](https://docs.tomorrow.io/)
- [Data layers / fields](https://docs.tomorrow.io/reference/weather-data-layers)
- [Free-plan rate limits](https://support.tomorrow.io/hc/en-us/articles/20273728362644-Free-API-Plan-Rate-Limits)
- [Pricing](https://www.tomorrow.io/pricing/)

## Gaps

The reviewed forecast documentation caps daily data at five days and does not list pollen. Use a second source for 10-day and allergies.
