# AirNow

- **Coverage:** United States, Canada, and Mexico observations/forecasts where reporting agencies provide data; primarily a US product decision.
- **Use it for:** Current AQI, observations, and available forecasts alongside NWS weather forecasts. It does not provide weather or pollen.
- **Pricing/licensing:** API key required; [terms of use](https://docs.airnowapi.org/terms) and attribution requirements apply. The API is free to use within documented limits.

## APIs

- [AirNow API documentation](https://docs.airnowapi.org/)
- [Current observations](https://docs.airnowapi.org/current)
- [Forecasts](https://docs.airnowapi.org/forecasts)
- [Historical observations](https://docs.airnowapi.org/historical)
- [API registration](https://docs.airnowapi.org/account/request/)

## Gaps

No weather forecast and no pollen/allergy data. Coverage and forecast availability vary by reporting location; display an explicit unavailable state rather than inferring an AQI.
